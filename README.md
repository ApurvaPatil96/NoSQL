# MongoDB College Database Project

This repository demonstrates MongoDB operations performed on a sample College Database (`collegedbs`).  

The project includes CRUD operations, query operators, sorting, limiting, indexing, and query performance analysis using explain().

---

## 📂 Database Structure

Database: collegedbs  

Collections:
- studentinfo
- teachersinfo
- courseinfo

---

## 🚀 Operations Performed

### 1️⃣ Create Operations
- createCollection()
- insertOne()
- insertMany()

### 2️⃣ Read Operations
- find()
- Projection
- Sorting (ascending & descending)
- limit()
- Conditional queries

### 3️⃣ Query Operators Used
- $gt
- $lt
- $gte
- $ne
- $nin
- $and
- $or

### 4️⃣ Update Operations
- updateOne()
- $set operator

### 5️⃣ Delete Operations
- deleteMany()

### 6️⃣ Indexing & Performance
- createIndex()
- getIndexes()
- dropIndexes()
- explain('executionStats')

---

## 🛠 Tools Used

- MongoDB 8.0.4
- MongoDB Shell (mongosh)

---

## 🎯 Learning Objectives

- Understanding NoSQL database structure
- Performing CRUD operations in MongoDB
- Using comparison & logical operators
- Sorting and filtering data
- Implementing indexing for performance optimization
- Analyzing query execution using explain()
